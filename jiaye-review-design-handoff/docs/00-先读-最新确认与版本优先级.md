## 3. 本轮最新确认的决定

| 编号 | 决定 | 具体边界 |
|---|---|---|
| N01 | 默认开局降低选择负担 | 生成一户合法家庭，查看一屏关键摘要即可开始；五步是可选的完整配置，不是必经教程 |
| N02 | 真正随机生成一家人 | 不是预写几户固定家族轮播；姓氏、成员姓名、人数、关系、潜力、本领、背景、家底、信物进入相应生成流程 |
| N03 | 名字可编辑，也可单独随机 | 名称随机不花点、不改变年龄/能力/资产；按成员命名归属同步本姓者，保留外姓和明确自定义姓名 |
| N04 | 三种随机分开 | 整户“换一家”、家族姓名骰子、可选配置中的“随机本页”拥有不同字段范围 |
| N05 | 随机结果必须稳定 | 切页、打开人物、查看预算、读取预计收支、保存、开始，都不重新生成同一户人家 |
| N06 | 清楚展示数值 | 当前资产、对应能力、资质、收支预测、信物作用、开局总分可读；不以“家境一般”等词替代数字 |
| N07 | 手机能装得下 | 数值透明不等于一屏塞满所有字段；首屏为关键摘要，明细点开，主操作可触达 |
| N08 | 原有核心玩法不变 | 纯文字、多代、全员可安排、族长可更换，家族是同一局持续主体 |
| N09 | 仍是一份100点预算 | 无类别配额，不自动删人降级；自定义超分可暂存，但所有开局入口拒绝超分 |
| N10 | 信物逐步解锁 | 初始三件可选，不是强制带入三件；保留 V5 已解锁多选并共享预算，不新加固定槽位 |
| N11 | 只先做凡世王朝 | 不因参考图出现修仙文案而加入修炼、灵根、延寿；其他世界后续单独讨论 |
| N12 | 终章有真实经历 | 发展条件满足后由玩家确认落笔；全体在世族人归零时“家谱落笔”，年度结算后公库与存粮同时归零时“家道散尽”；100+是内容目标，不是已实装数量 |

N02不是“每次必须把所有字段都变成不同值”。合法随机允许偶然重合；但不能由固定四个人换姓来冒充整户生成，也不能强迫玩家用模板选择代替随机。

## 4. 明确废弃或降级的做法

- 固定林家、谢家、贺家作为每次开局的主角：废弃；这些只可作为截图示例和测试夹具。
- 几户预制家庭轮播冒充“换一家”：废弃。可复用关系结构生成器，不能以少数成品家庭作为全部结果。
- 将五页配置作为进入游戏的必经步骤：取消。原编辑能力保留并可直达修改。
- 默认摘要无限向下列出每人的全部数值：取消。关键数值首屏、完整数值详情。
- 默认满分/97点作为唯一目标，要求用尽剩余点数：取消。不满100可开始，不给“浪费点数”压力提示。
- 把最新概念海报逐字转成剧情/价格/信物注册表：禁止。图中的文字、名字与数值可能有生成误差。
- 为复制插画主页新增一个需要经营建筑或战术移动的大地图系统：不在本轮范围。

## 5. 仍然继承的旧要求

一个总预算；时期与可选年份联动；所有成员可安排；人物取消编辑恢复；每页随机不动别页；出售信物取消未完奖励但保留历史；Profile 与当前 Run 分离；换任不清空其他人；人物与家史永久可查询；成长/传承/结局认真实事实；存档异常不能假报成功。

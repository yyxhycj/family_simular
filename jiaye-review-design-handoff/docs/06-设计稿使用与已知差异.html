2. 明确不能照抄的内容

**固定家族。**谢氏、林氏、贺氏等只是某一次随机结果，界面、事件、族谱、结局统一引用本局数据。综合稿中的“多种家庭示例”表达随机结果变化，不是把游戏改为几户固定模板列表。

**图片中的数值。**97/100、80两、24石、+3两、+18两等都是示例或旧夹具快照。不能拿图片独立定价；正式来源是当前已批准价格/经济配置，并用同源函数计算。发现示例总计不一致时修正画面，不篡改引擎凑数。

**概念文字与新物件。**生成式海报可能有错字、不一致年号/职业/性别称呼、虚构的青铜罗盘等。未经注册的信物不能进入基础解锁池；基础七物的事件与作用先照正式内容。文案回到实际成员ID、物件ID、世界ID生成并校验。

**健康只有“良好”。**形容词可以辅助，确切数值仍须可访问。能力条与资质分开。不要让背景文字替代关键数字。

**插画场景。**庭院/村落可做装饰或带文字的功能入口；不因此新增需要资源建设的地图、角色走位或战斗。参考产品的修仙境界/功法等不进入凡世。

**头像、美术版权。**同类产品截图只用于研究布局与信息分层；不要裁出角色、标识、边框直接作为发布素材。综合概念图不是分层可编辑资产库，也不是可直接发布的完整美术包。包内没有字体文件。

**系统状态栏。**截图中的9:41、电池、底部横条为设备示意；实际平台尊重系统状态栏与安全区，避免重复占位。

3. 图片浏览器的边界

design/VIEW.html 可切换设计图、缩放和打开原图；没有游戏交互。其360/390/430按钮只是静态图的展示宽度，不证明适配已通过。需要真实布局对照时进入现有V5互动原型，但它尚未接入本轮真随机紧凑开局。

4. V5保留而不冒充新版

baseline/v5/prototype/ 原样保留。可以操作旧规则、配置与游戏；其中固定样例、五步默认入口、旧版视觉只作为行为基线。没有新的V6游戏HTML可交付，本包没有把图片包进iframe就声称最新版玩法已经可操作。

原方案中的27步骤、原88条验收设计及原检查报告也在baseline；它们保留原日期与范围。新的默认入口、名字随机、信息分层等以本包补充为准。旧“V5是唯一基线”的优先级被本包的最新确认覆盖。

整合包R1 · 当前用户确认优先于旧版原型。新规格不是已实现证明；图中示例不构成数值定案。

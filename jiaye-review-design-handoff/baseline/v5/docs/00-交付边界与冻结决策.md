## 1. 如何判断哪份文件有效

优先级为：**用户最后确认的规则 → 本包冻结决策 → 本包目标规格 → V5 可运行实现 → archive 中的旧文档**。新增加的实现策略标记为“实施建议”；没有得到用户明确确认的平衡参数只能作为原型基线，不能被包装为最终定案。

`prototype/jiaye-demo-v5.html` 是当前交互与视觉参考。`source/prototype/` 是从同一文件原样分离的 CSS / JavaScript；它不是已经模块化的正式游戏工程。`archive/` 不参与正式规则读取。本文档不启动重设计，不替换已确认的 V5 视觉。

## 3. 明确解释容易冲突的地方

**预算只有一份。**总成本 C 为全部选项成本之和；本页成本 P；其他页 O=C−P；本页容量 A=100−O；可继续投入 R=A−P=100−C。总分不足 100 也允许开局。确认页不增加费用。如果其他页已超分，A 可以为负；界面可把容量绘制为 0，但要额外说明“其他页已超出”，不能把负值清零后允许随机或开始。

**初始信物三个，是可选目录数量。**V5 实际允许从已解锁信物中多选，只受同一总分约束。本交付保留该行为，不重新施加“必须且只能带一件”的旧建议；是否额外限制装备/携带槽属于将来明确评审项。实体物件在局中可以继续获得，局外解锁资格与本局物件不同。

**100+ 是完整内容目标。**144 条旧目录是素材库，不是 144 条已开发事件链，也不承诺每个世界各 144 条。先把凡世路径做完整；正式结局发布数量单独计数。

**发展条件满足不强制截断。**先取得终章资格，玩家确认一个主终章，本局转只读。没有在世成员等确实不可继续情形可自动终章。跨世界迁居后仍继续本家族时叫“篇章转折”，不同时声称本局已结束。

**时间不直接产生经历。**世界历 156 年开局不是经营 156 年；开局祖孙三代不是玩家已经完成三代培养。本局职业人年、继任、托付、复兴证据从实际行动产生。

## 4. 现有 / 目标 / 待讨论

**原型可见且有处理函数：**五步创建、总分与按页预算、时间联动、人物编辑、随机与撤销、家谱预览、主业持续安排、应试与出师节点、成年婚配、生育意愿与简化出生、收养、主动换任、年度结算、简单时代变化和整族迁居、七件信物及其故事处理、十三个终章判定、导入导出、移动视图。

**原型简化，正式实现仍须工作：**经济平衡、随机种子一致性、结算事务、关系真实性、人物动机、时代因果、存档可靠性、长局性能、无障碍、跨浏览器与真机体验。

**目标但未完成：**个人/小家庭财产、可经营异地支系、丰富人际关系与外部势力、完整官场军伍线、完整信物分叉与跨代因果、上百条经验证的结局、其他世界及真实跨界迁移。

**暂不要求：**账号云存档、联网经济、付费抽卡、原生安装包、AI 实时生成裁定。先保留本地单人、离线原型；是否做服务端、哪种移动封装、何时引入生成式文案，在对应实施步骤再决策，不挪用其他项目的技术栈。

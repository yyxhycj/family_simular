# 01 · 游戏总案与凡世王朝

## 1. 游戏定位与体验目标

《家业》是纯文字、多代、全员可安排的家族人生模拟器。玩家始终管理整个家族，族长只是其中一个可更换职位。每个人都具有年龄、能力、当前生活安排、亲属关系与持续经历。玩家通过安排个人、经营共同家业、处理事件与选择继任者，形成能追溯原因的家族历史。

核心感受不是“把一张资产表做大”，而是“当年由我安排的这个孩子，如今接过了家族；他做过的事又在影响下一代”。普通人也必须有价值：养家、照护、教书、保存技艺与维系关系，不只是高资质人才才值得关注。

## 2. 三个循环

**单次操作：**看清处境 → 选择人物或家族事项 → 查看可用选项、花费与条件 → 确认 → 看到实际结果和出处。不能点击后只有一个数值跳动，没有对应的人物/家史记录。

**一轮年度：**查看近况 → 调整主业、生活计划和共同事务 → 处理待决事件 → 推进 → 收支结算、成长与世界变化 → 重要新事件暂停。普通小事合并成摘要；关键转折保留决定权。

**跨局循环：**自由配点 → 经营与探索 → 完成真实信物故事 → 解锁新的开局选项 → 达成某个家族终章 → 再次在同一个总分内构造不同的家庭。局外成长主要横向增加内容，不持续扩张总分。

## 3. 第一世界的边界

凡世王朝暂名“大晟”，是架空古代，不照搬某一真实朝代。普通人有限寿命，无修炼、灵根、超自然延寿或祖灵直接操控。可以有信仰、传闻与未来跨世界线索，但不能让玩家靠神迹替代谋生、照护和培养。

从一户家庭起步，可发展为手艺之家、商族、书香家族、医者之家、地方望族，亦可平凡延续、分散迁居或几度重建。战争、官场、地方势力通过成员任务、资源与文字事件表现；不改造成战术战斗或地图建造游戏。时代改变不自动结束家族。

六条个人路线：耕作、手艺、商业、求学仕途、医道、军伍护卫。料理家事和休养是有效生活安排，不应只是无收益闲置。路线允许中途变更；已经学会的能力和做过的事情保留。

## 4. 个人玩法

### 4.1 能力结构

保留“潜力 / 已学本领 / 性格兴趣 / 健康”分离。当前 V5 用资质 1–5、学识/手艺/医术/经营/武艺 0–100 和体魄表达。正式版可细化，但新增指标必须实际参与行动、事件或反馈，否则不加。

资质提高成长效率，不直接赋予资格。已经积累多年的普通人可以比刚入门的高资质孩子更可靠。性格主要影响过程与关系，不频繁以随机拒绝否定玩家安排；出现抗拒时要有可见原因、持续预兆与解决办法。

### 4.2 主业与其他事务

每人一个主要长期安排，持续到玩家修改或出现必须重新决定的人生节点。婚事、照护意愿、信物调查、居住地属于独立状态，不因更换主业丢失。V5 的调查不占主业；正式版是否计入时间负担必须写成明确规则，不隐性减少收入。

出师只生成可选转折，不自动转行。通过应试后也由玩家选择任职、继续教书或读书。职业资格不满足时给出原因和成长方向，不能只禁用按钮。

### 4.3 家庭与成长

成年婚配需要双方有效且非禁止近亲；新加入者有独立身份和安排。婚配与立即生育分离；生育意愿可开关、需要满足年龄及生活规则，结果不是必然。收养形成真实亲属和监护记录，养子女成年后拥有同等可选择的族长资格。

孩子有自己的记录，不默认马上开启有费用的教育；发生启蒙机会时应提示成本并尊重既定安排。老人可以继续承担适合的工作或退休，死亡保存整段人生和关系。暂时只剩孩子时提供明确的临时照护状态，不立即结束。

## 5. 家族经营

### 5.1 公共资源

最小可运行版本包含银钱、口粮、住宅、田产、作坊、商铺、声望与已经承担的义务。任何资产描述需要对应实际效果：作坊的收入需要有人经营；地点会影响某类职业而非一律加钱；买卖、经营、赠予分别记录，避免重复收入。

### 5.2 目标中的个人与小家庭

后续引入个人积蓄、家庭单位与共同公库，明确工资归属、寄回金额、培养补助和债务归属。先保持一套清楚的默认分配，让不想微调的玩家能直接过年。查看明细时才展开个人收支，主界面仍看可动用资金和关键承诺。

分家/在外生活不意味着从可操作名单消失。支系既能汇总，也能进入每个人；未实现异地经营时，菜单必须写“暂未开放”，不能把不可操作 NPC 叫成可经营旁支。

### 5.3 关系与选择

重要援助、牺牲、失约、教育投入和传授技艺建立关联记录。某次争执要能指出起因，不靠随便抽到“反目”让昨日亲密的人突然失常。资源紧张增加矛盾可能，但不能保证产生悲剧；也要有和解、回报和普通日常。

## 6. 族长与代际

任意在世成年且满足明确世界规则的族人可由玩家任命，不限定性别、主支或亲生关系。主动换任不清除其他成员安排，不重置时间，旧族长继续自己的生活。

正式定位是主持共同事务与对外联系，不是全能增益装备。任职经验、人脉影响共同计划的执行，不改变他人技能事实。原型尚未有完整治理系统，不把候选标签夸大成已存在的家族自治。

同一年往返换任可以真实记事，但不增加用于结局的有效传承次数；有效交接应记录前后任、在任区间与不同身份，不能只用任数列表长度判断。暂无成年候选时用临时监护，等待成长。

## 7. 世界、时间与迁居

世界历、当前时代状态、本局实际年数和成员年龄分别记录。开局选项使用一条明确的时期—年份—时世映射。进入游戏后的时代变化依据世界状态；世界日历是日期，不保证下一年又被开局映射强行改回旧状态。

正式世界事件应有趋势、预警、影响范围和恢复过程。商路紧张对行商、教书、农户影响不同；不设计人人固定损失同一笔钱的“世界事件”。V5 目前为简单概率时世转换，此处是完善方向，不是现状描述。

同世界迁居要明确费用、旅程/生计影响、产业如何处理、成员是否同行、落脚后机会变化。V5 只有整族地点转换，不把它解释成完整异地支系。跨世界迁移不在首个世界交付范围。

## 8. 事件与叙事

三层阅读：当年摘要、重要事件正文、人物/家史详细记录。前两层保证用手机可读；第三层允许追溯。每次选择同时显示故事表达、资源支出、确定效果、概率或延迟结果；未知故事内容可以隐藏，致命规则不能隐藏。

事件至少来自人物阶段、主业、关系、资产、世界趋势、信物之一。重要选择有后续并指回原因；日常也有正向回报，不让整局只有灾难。关键调查入口要可触达、可暂缓后恢复，不依赖几十年没有保底的抽签。

基础模拟必须不依赖大模型正常运行。未来可以添加文案润色，但结构化规则和事实是唯一判定依据；生成失败用模板降级，不能让模型随便修改家产、亲缘或生死。

## 9. 终章

阶段成就不终局。发展终章：条件未满 → 有资格 → 玩家确认 → 结局快照 → 本局只读。不可逆终章：明确不可继续 → 自动结算。仍可翻阅成员、任职史、信物史和年鉴，不允许从只读页继续写入。

一局一个主终章，其他已经满足的方向可记在回顾中，不一次把所有主结局刷成完成。最后必须写清实际人物、时代、关键转折，不能用开局不曾拥有的“三亩薄田”套所有家庭。

## 10. 版本交付层次

第一层是 V5 等价重构，不变玩法不变视觉。第二层把凡世核心做到一致、可靠、可长局。第三层增加人物关系、个人财产、支系与丰富世界内容。第四层完成经验证的多路线内容，再逐个讨论其他世界，累计达到至少一百条有意义的正式结局。

每层都必须能独立游玩。不以“未来会接 AI / 加一百个事件”掩盖当前没有可运行的核心循环。

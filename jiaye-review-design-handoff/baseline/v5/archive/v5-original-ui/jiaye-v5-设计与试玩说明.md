# 《家业》V5 · 手机优先 UI 重设计

## 打开方式

- `jiaye-v5-mobile-preview.html`：桌面上直接预览 390 / 360 / 430 像素的竖屏交互。同一份实际游戏运行在预览框内。
- `jiaye-demo-v5.html`：完整自适应单文件网页。手机浏览器直接打开这个文件，或放到静态站点后访问。
- 预览框内不需要联网；所有游戏脚本和样式都已包含。

## 本次设计

视觉采用墨绿、米白、低饱和草绿色，保留纯文字、书页式标题与家族印记。未添加角色插图，也未重写游戏题材。

1. **开局**：手机端五步导航；选项改为可整卡触摸的单列卡片；底部显示本页点数并保留下一步。家谱和点数明细可以单独展开，避免三个桌面栏挤在一起。
2. **游戏主界面**：家族近况、族人、家业、藏阁、家史五个底部入口。历代族长、年鉴与结局依旧可达，不删除已有内容。
3. **人物**：族人列表改为竖向信息卡片；个人安排使用整屏详情、固定保存区以及概况/安排/经历章节定位。
4. **事件**：加大正文与选项间距，区分故事、影响与确认操作。
5. **信物与结局**：保留原有真实状态、解锁条件和进度，以单列卡片呈现。未解锁或未实现内容仍使用原有规则，不伪造完成状态。
6. **移动操作**：适配安全区、竖屏滚动、底部操作和弹层；输入框采用 16px 字号，主要操作采用 44–49px 高度。支持键盘焦点和减少动态效果偏好。

## 保留的玩法

保留 V4 的全部原有模拟脚本，只更换样式并增加视图适配层。总预算100、各页共用额度、时期/年份联动、超分拦截、每页随机及撤销、族人安排、族长交接、年份推进、信物事件与解锁、结局判定继续由原有函数执行。

本版没有新增或宣称补完其他世界、144条实际结局、云存档、原生App。它仍然是凡世王朝的玩法原型。

## 存档

V5 使用独立本地存储键 `jiaye_mortal_demo_v5_0`，不覆盖V4。文件浏览器与内嵌预览器的存储策略可能不同；跨文件/跨设备迁移请使用原有导出与导入功能。原有导入校验未放宽。预览框与完整页面可能拥有不同的存储空间。

## 交付与检查边界

这是HTML界面重设计，不是已打包的iOS/Android安装包。桌面浏览器模拟窄屏不等于真机Safari/Android浏览器测试。实际检查结果见随包的检查记录（如有）；未运行的设备不宣称已验证。

`mobile-ui.js` / `mobile.css`为本次新增表现层，已内嵌到单文件中；V4原有价格、人物、事件与存档结构不变。

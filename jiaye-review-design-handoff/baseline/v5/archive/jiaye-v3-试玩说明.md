# 《家业》V3：凡世王朝 · 试玩说明

这是一份可以连续操作的纯文字家族人生原型，重点验证自由配点、全员安排、族长交接，以及信物故事与跨局解锁。所有人物与世界均为虚构，参数用于试玩，不代表最终平衡。

## 打开与保存

直接用浏览器打开 `jiaye-demo-v3.html`，无需安装、构建或启动服务器。页面不加载外部图片、字体、脚本或接口。

进度会尝试写入当前浏览器的本地存储。浏览器、文件路径、隐私模式及存储权限不同，可能导致无法恢复同一份进度；页面会提示存储不可用的情况。重要进度请使用“导出一份存档”，得到 JSON 文件，之后可以导入。

V3 使用独立存档键，不读取或覆盖 V1、V2。没有账号、云同步或后台联网。

## 先体验这一条流程

默认家庭已配好，合计 **97 / 100 点**。可以直接进入第 5 步“落笔之前”，也可以先自由调整。

1. 在“世道与来处”选择“旧日名门”，总分会变成 115。家里的人、资质、钱粮和信物不会被自动修改。可以自行减少其他配置，也可以改回来。超分草案允许保留，但不能正式开局。
2. 沿用默认 97 点、携带“一把老木尺”开局。选择花费 8 两寻访旧匠号，再推进一年。
3. 收到后续后，选择修复旧图。这会花费另外 8 两，并解锁“修复的营造图”作为以后开局可选的信物；不会无说明地把营造图复制为这一局的另一件物品。
4. 点“信物藏阁”，查看从 3/7 变成 4/7 的收藏。返回家族后，仍可调整每个成员、换族长和继续生活。
5. 开启另一家族时，总分上限仍是 100。可以带入已解锁的营造图，但需按它的价格重新配点；不必带入。正在进行的家族将被替换前，会要求确认。

游戏内的默认安排会持续执行。学徒达到出师条件后，有事件供玩家选择是否开始谋生，不会悄悄替玩家改变人生方向。

## 开局：一个总上限，没有分类配额

判定公式是：**选中项目的分数总和 ≤ 100**，加上基本的人物关系合法性检查。

世道、来历、地点、各个成员、资质、本领、家底、家风、人脉与信物共同占用预算。右侧按类别汇总只是帮助核对，不代表分类预算。剩余点数可以不用完，也不会兑换为本局额外资源。

可以自由增删、编辑成员；首任族长单独选择。不收费的表达项包括姓名、性别、家族称谓等。父母子女年龄差、成年婚配和相互关系需要成立。因技术防错设置的输入范围不构成分类配额。

## 实际可操作的内容

### 全员人生与交接

14 种持续安排，包括生活、读书、耕作、学艺、手艺谋生、经商、教书、学医、行医、习武、护卫、地方任职、料理家事、休养。根据年龄与已有本领显示可选行动。

每个人有自己的年龄、资质、能力、主业、亲属与传记。支持婚配加入新成员、生育意向、简化自然生育，以及收养。加入的人仍能单独安排。

任意在世成年人可以担任族长，不限定性别、血缘直系或前任的孩子。主动换任、前任离世后继任，都保留其他人的安排与经历。同年反复换任不能刷真实传承条件。

### 家族岁计与家业

支持持续推进、年度收支、粮食不足补购、基本生活压力、成长衰老、出生离世、简单时代变化、援助邻里与家宅事件。没有固定年数上限。

可以购买田产、产业和住宅，买卖粮食，并进行简化的全家迁居。钱粮、经营方向与成员安排会影响接下来的生活。

### 信物藏阁与本局旧物

共有 **7 件带有实际故事内容的信物**，初始解锁 **3 件**：

| 信物 | 如何成为开局可选项 | 本局故事 |
|---|---|---|
| 一本旧族谱 | 初始解锁 | 查明谱中遗漏的记载，可解锁补完的族谱 |
| 一把老木尺 | 初始解锁 | 寻访旧匠号、修复图纸，可解锁营造图 |
| 一封未拆的家书 | 初始解锁 | 完成旧约，可解锁故人的半枚玉佩 |
| 修复的营造图 | 完成木尺对应分支 | 修造旧桥，获得工钱与声望 |
| 补完的族谱 | 完成旧谱对应分支 | 接回一位可单独安排的成年旁支 |
| 故人的半枚玉佩 | 完成家书对应分支 | 查证另一半物件与两家的关系 |
| 批注医案 | 累计行医 6 人年，且在世族人医术达到 55 后处理赠书事件 | 实际得到医案，选择刊印传授或保留研究 |

藏阁表示“以后可以选”；家中旧物表示“这一局真正拥有”。解锁保存到玩家档案，不提高开局点数，也不让所有收藏效果自动叠加。

可选择谁来调查，可暂缓并重新展开，可换保管人，可出售。调查不会覆盖人物的长期主业。卖掉调查中的信物会取消对应后续，避免仍然获得不应存在的奖励。

### 凡世终章

本版接入 **13 个实际判定的演示结局**：炊烟未断、书香传家、商脉长存、百年手艺、杏林人家、四时有余、一村归心、异乡生根、归来有灯、迟来的家书、木尺新纹、家谱再续、家谱落笔。

发展结局达标后只获得落笔资格，玩家可以继续经营。确认一个主终章才结束本轮，之后仍能查看人物与年鉴。全族都已离世才触发自然终局；某一任族长死亡、破产或族长没有孩子不自动结束。

上一版 **144 条结局设计母表**保留在源文件 `catalog.js`，界面按凡世适用范围筛选，并将未接入条目标明为“设计条目”。不能把它们算作 V3 已完成的可玩结局；13 条演示判定也不是承诺完整游戏只有 13 条。

## 本版暂未完整制作

只运行凡世王朝，其他世界与跨世界迁移没有接入。没有完整官场、军伍战争、大地图、分家并行经营、个人财产分账、复杂遗传、动态亲族性格或长期社交网络。

当前来历、人脉主要通过数值效果验证配置，尚未全部扩展成独立事件链。当前族长以负责人、交接与记录为主，复杂协调能力尚未制作。收入、人口、寿命、考试、迁居、时代事件均为简化规则，不是历史考据或最终平衡。

迁居使用全家共同搬迁的演示模型，保留家业账面记录；没有分别处理异地不动产、留守支系与真实交通成本。信物故事为短事件链，不等同于完整世界剧情规模。

## 源码与构建

压缩包包含可直接打开的 HTML 与 `source/` 源码。只试玩无需运行任何命令。

修改源码后，可在解压目录执行：

```bash
python3 source/build.py
```

会重新生成根目录 `jiaye-demo-v3.html`。脚本仅使用 Python 标准库。JavaScript 使用原生浏览器 API，不依赖 npm 构建或第三方运行库。

- `data.js`：选项、价格、默认家庭、存储定义。
- `core.js`：预算、结构校验、年度模拟、事件、信物与结局。
- `ui.js`：创建流程、各游戏页面与收藏展示。
- `actions.js`：人物编辑、弹层、经营操作、存档导入导出。
- `catalog.js`：原 144 条结局设计母表。
- `base.css` / `v3.css`：沿用的纸质风格和新页面适配。

## 检查

```bash
python tools/build_prototype.py
python tools/verify_package.py
```

上面仅需Python标准库。选跑浏览器检查需要Python Playwright与Chromium：

```bash
python qa/smoke_v5.py --chromium /实际路径/chromium
```

本轮38项冒烟通过，使用桌面Chromium+set_content+内存Storage替身；不代表真机、真实本地文件存储、全内容长局已经验收。88条正式测试为设计清单，默认未执行。原始V5检查记录留在archive且不作新的通过声明。

## 保存与交付

Demo不需要联网，但不同浏览器/file/iframe的本地存储策略可能不同；重要进度使用JSON导出备份。源码原样保留V5存储键，不覆盖V4。这个ZIP没有云服务或移动安装包，也没有分发字体文件。

`MANIFEST.json`列出交付文件、字节和哈希；修改文件后出现差异是预期，重新冻结前应先审查。设计日期2026-09-11，用户确认规则优先于旧归档。

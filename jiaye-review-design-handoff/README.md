# 《家业》评审与手机设计整合包 R1

先打开 **START_HERE.html**。所有入口都可离线打开，无需安装或启动服务。

## 三个最常用入口

- `docs/00-先读-最新确认与版本优先级.html`：开局简化、真随机、数值透明、手机信息分层的当前规则。
- `design/VIEW.html`：最新综合概念稿、4张独立竖屏稿、随机开局状态板；这是静态稿浏览器，不是新游戏。
- `review/报告阅读版.html`：18项历史审查条目与原8探针材料。

## 目录

| 目录 | 内容 |

| docs | 最新规则、评审整改对照、逐屏绑定、12步实施、42条验收设计、AI执行提示词 |

## 必须注意

1. 最新用户决定→docs/00与02→最新设计图→仍有效评审→V5未覆盖规则→旧资料。
2. 家族名/人物/开局是真随机，不固定姓氏，不是几个成品模板轮播。
3. 默认一页查看后开始；原五页是可选完整编辑器，不强制填写。
4. 信息精简不等于藏数值；数字绑定状态与同源计算，图片中的数字/人物/信物只是示意。
5. V5可以操作，但没有本轮新增紧凑随机开局。最新稿尚非可运行新版，本包未修改GitHub。
6. 原评审固定在546ff6cf7e4225632fe9871ba70188e6aa730e82；不是对现在main的重新检查。
7. 8探针原结果是问题复现，不是功能通过；本次42条新增用例未执行。真机/UrhoX未在本次运行。
8. 参考产品图片不得直接用作发布美术；没有字体文件，也没有分层Figma工程。

## 快速交付开发

读 docs/04-AI开发执行提示词.md，从T00开始，按 docs/03 分步交付。不要直接从baseline中的旧总提示词开始。

## 完整性检查

在解压目录运行：

```sh
python3 tools/verify_package.py
```

该脚本只校验清单与文件哈希，不执行游戏、不连接网络、不证明功能已正确。

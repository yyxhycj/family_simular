## 迁入规则

顶层保存格式使用 `saveSchemaVersion = 2`。现有 `profile`、`draft`、`run` 的内部版本保持原值，并在读取时补全 T06–T09 新增的事实、账本、执行命令、指标和人物运行字段。

`schema = 3` 的 V5 备份映射为当前的收藏、草案和运行家谱：

1. V5 `unlocked`、`records`、`endings` 映射为信物资格、解锁记录与终章记录。
2. V5 草案的时期、来历、落脚处、住宅、家业、信物、成员关系和首任族长映射为当前草案字段。
3. 外姓、复姓和手改姓名保持原文本；仅姓名以家族称谓开头时标记为家姓姓名。迁入 `许青` 的 `nameSource` 为 `custom`。
4. V5 运行家谱映射成员能力、人生记录、族长任期、日志、物件、待决事件、终章、指标与随机状态。V5 无符号随机数固定转换到当前随机数范围，迁入后每次回读值一致。
5. 木尺等已到期调查迁入为当前 `relic_resolution`；其他旧待决家事保留原始详情，确认后追加一条迁移事实。

读取和导入会校验保存格式、收藏和终章引用、草案人物与关系、运行成员、族长、任期、物件、待决事件、事实参与人和终章引用。运行家谱使用开局当年的原始数据，不按后来价格重新判定预算。

## 正常路径

1. 封面或家史页点“导入备份”，粘贴完整 JSON 后点“校验并预演”。此时内存和磁盘均不写入。
2. 预演显示来源、经营年数和待决家事数；确认后写入交替保存位，再回读同一份内容。
3. 写入完成后重新载入当前资料、草案和运行家谱，回到开局或游戏页。历史、收藏、运行状态和随机数来自同一份保存内容。
4. 同一备份再次确认时，导入收据命中，保存修订号和游戏事实不增加。
5. 导出前校验当前内容，写入后回读 `jiaye_export.json`。成功提示只在回读成功后出现。

## 失败路径

| 情况 | 结果 |
| --- | --- |
| 空内容、超过 15MB、JSON 损坏或未知版本 | 预演拒绝，当前内容保持原样 |
| 未知信物、终章、族长、亲缘、物件、事件或事实参与人引用 | 预演拒绝，当前内容保持原样 |
| 两个旧保存位均不可读 | 普通保存停止覆盖；经预演并确认的导入可建立新的可回读保存位 |
| 导出写入或回读失败 | 返回失败提示，当前内存和最近可读取保存保持原样 |
| 再次确认同一份备份 | 返回已导入提示，修订号、资源、历史和收藏不重复增加 |
| 迁入普通待决家事 | 原始详情进入迁移事实；旧版结算不重复写入 |

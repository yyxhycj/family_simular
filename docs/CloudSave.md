# 账号云存档

正式入口 `scripts/main.lua` 提供 TapTap 登录和游客登录。玩家选择 TapTap 登录并取得宿主有效会话后启动账号同步。完整存档包含收藏、开局草案、当前家谱、人物、家史、账本、待决事件和随机数状态。

## 登录方式

- TapTap 登录使用 Maker 宿主提供的真实账号和项目绑定，按钮使用 TapTap 官方设计资源。未取得授权或缺少项目绑定时，登录页显示原因，保留游客入口。
- 游客登录只读写 `jiaye_save.json` 和 `jiaye_save.backup.json`，不创建云同步服务。游客与 TapTap 账号各自保留进度，切换时读取对应家谱。
- 首页及家谱事务提供切换登录方式入口。切换前保存当前已确认的安排；保存失败时保留当前会话，提示重新保存。账号的待上传进度保留在该账号的本机文件中，下次登录继续同步。
- TapTap 会话失效、切换账号或项目绑定变化时，停止原会话的同步，重新显示登录页；旧会话回调无法写入新会话。
- 网页预览的游客存档位于内存，刷新或退出后会丢失。原生设备使用本机持久文件保存游客进度。

当前 Maker 公开 Lua API 提供已登录账号信息及云变量，没有游戏内主动唤起 TapSDK OAuth 授权的接口。TapTap 授权由宿主在游戏启动前完成；游戏内 TapTap 按钮使用该授权会话进入账号家谱。独立安装包内直接唤起 TapTap 客户端或 WebView 授权需要 Maker 提供对应入口。

## 本地开发

桌面引擎带 `-skip_login` 启动时进入本地开发模式，窗口标题显示“千家纪 · 本地开发”。登录页选择游客登录后进入游戏，安排族人和修改完整开局草案后自动保存到本机。

开发存档使用 `jiaye_development.json` 与 `jiaye_development.backup.json`，独立于账号存档和旧版本机存档。开发模式不启动云同步，开发进度保留在本机。

登录及项目绑定由引擎负责。初始化云存档要求 `clientCloud.userId` 为有效账号，且 `clientCloud.mapName` 为非空项目标识；条件不满足时立即报错并停止初始化。每次发送请求和处理回调均核对账号及项目，运行期间项目变化会停止同步。页面中的“重试同步”重新发起云变量请求。

官方本地单机预览使用 `-skip_login`，按本地开发模式运行。Maker 在线预览使用引擎提供的真实 TapTap 账号及项目绑定。本地原生联网环境的登录、云读写和进程重启恢复尚未完成验收，其结果与 Maker 在线预览分别核对。

## 保存与续玩

- 玩家选择 TapTap 登录后读取账号云存档。读取完成前暂停进入游戏和写入进度。
- 新局和每次已确认的游戏安排都会自动保存；完整开局草案的修改每两秒检查一次。
- 本机使用两个交替文件保存，写入后回读核对。账号 ID 与云变量名称共同构成本机文件名称。
- 云端使用 `clientCloud:Get`、`clientCloud:Set`。上传前读取当前版本，上传成功后再次读取并核对内容。
- 换设备登录同一 TapTap 账号后，完整恢复云端家谱。旧设备再次打开时，自动接续同一条历史上的新进度。
- 上传期间新增的安排继续保存到本机；前一次上传确认后自动续传最新进度。
- 游戏回到前台或失去焦点时立即发起同步。“家谱存档”显示当前同步状态和本机、云端保存时间。

## 存档界面

首页和家谱事务提供“家谱存档”入口。详情以底部面板显示家族、年份、人数、银粮及保存时间，并提供立即同步操作；同步过程中暂停重复点击。正常经营保持自动保存，页面顶部专注显示游戏内容。

本机已确认保存、云端暂未同步时，显示一次短暂提示；家谱事务保留“待同步”状态。后续自动重试保持安静，详情中可以查看原因。网页预览明确提示会话数据的保存范围，提醒刷新或退出前完成云端同步。

首次读取账号进度时显示独立读取页；读取失败后提供重新读取，错误详情默认收起。本机写入或读取失败时暂停继续经营，保留现有家谱并提供对应重试操作。

进度冲突页展示两份家谱的来源、年份、人数、银粮和保存时间。玩家先选择家谱，再确认续写；确认前保留两份进度。页面内容支持滚动，确认操作固定在安全区域内。

## 网络与冲突

请求超时或网络中断后按 2、4、8、16、30 秒间隔重试。待上传版本号、所基于的云端版本号和当前进度一并写入本机文件，重启后可以继续核对并上传。

云端和本机各自发生变化时，暂停游戏并显示两份家谱摘要，玩家可以选择使用云端进度或本机进度。选择本机后，仍会重新读取云端版本，确认期间出现的新变化继续进入冲突选择。每份云存档保留最近 64 个祖先版本号；无法证明属于同一条历史时也进入选择流程。

TapTap 云变量接口提供普通读取和写入。服务端未提供条件写入接口，同一瞬间的多设备写入无法实现原子互斥；客户端通过版本历史、上传后的回读以及各自保留的本机进度识别分叉。

原生设备可以保留尚未上传的本机进度。WASM 预览的文件系统位于内存，刷新会丢失尚未同步的数据；应等待页面显示“家谱已自动保存到云端”后再刷新或切换设备。

## 数据位置

- 云变量：`jiaye_save_v1`，由 Maker 按当前项目和 TapTap 玩家隔离。
- 本机文件：`jiaye_jiaye_save_v1_<账号ID>.json` 和对应的 `.backup.json`。
- 云端数据版本：`format = 1`；游戏存档版本沿用 `State.SAVE_SCHEMA_VERSION`。
- 游客家谱与账号家谱分别保留。账号本机进度与云端存在分叉时显示选择页面。

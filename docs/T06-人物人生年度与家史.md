- `scripts/Jiaye/Simulation.lua`：岗位、应试、婚入、收养、生育、成长、继任和离世都写同一份事实；年度结算冻结年初钱粮田和收入/培养/产业/生活/粮食分项；离世后物件回到“家中”，不再指向已故保管人。找不到族人的成长提醒会安全作废。
- `scripts/Jiaye/App.lua`：岗位改为预览后确认，取消不改运行态；人物“经历”从事实读取；成长只提醒，不偷偷转职；家史增加“历任族长”“年度账本”和任期到人物生平入口。
- `tests/t06/*`：只验证 T06 的状态、事实、保存和 UI 绑定，不替代 UrhoX 绘制或真机验证。

## 正常路径

1. 年度推进前冻结钱、粮、田和在世成员安排；结算后生成不可回写的年度账本，年初、收入、培养、产业、生活、粮食和净变化来自同一正式结算。
2. 生育、收养和婚入分别按真实代际入谱；同代婚入不会被当成下一代。成长成年或具备出师资格时给出提醒，仍须玩家确认岗位。
3. 岗位、应试、婚入、收养、生育、继任和离世进入人物经历；任期引用同一事实，可从家史跳到对应人生平。
4. 族长或其他成员离世后，所有由其保管的信物实例回到“家中”；已故成员仍可打开，只读回看离世与此前经历。

## 失败与保护路径

- 饥荒年度不计稳定和食足连续值，成员健康承担后果；不会用账面叙述掩盖失败。
- 岗位确认页取消时运行态、资质和经历不变；确认后才写岗位事实。
- 成长提醒指向已不存在成员时标为 `cancelled`，返回失败提示，不遗留“已解决”却没有人物事实的事件。
- 无法继任时不把保管权交给已故族长；待决继任仍由事件处理。

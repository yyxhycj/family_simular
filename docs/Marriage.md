# 议亲、亲家与传承

年满18岁、在家且没有在世配偶的族人，可从人物首页「议亲成家」进入。丧偶后可以再议亲，原配偶与旧婚约继续保存在家谱中。已有婚约从同一位置查看「婚约与亲家」。

## 对象与婚约生成

每局用开局种子生成亲家家庭，保存经历、家产、眼下诉求、具体长辈的身份与退任年龄，以及成年子女的能力、天资和个人愿望。家庭来历、身份、资助方向与家法独立组合。家资包含银两、粮食、田产与唯一书册、图纸。

每位可议亲族人能获得3位对象的引见。联谱完成后增加2个引见名额，有效3年。同一家子女共享家产、援助名额、身份事务次数与唯一物件。对象按年增长年龄，并可能另结姻缘；名单不足时补充新家庭。打开页面、查看报价、存取档均沿用已有对象。

每位对象提供「各尽心意」与「相助成家」两份婚约。个人留乡意愿限制可选居所；家庭诉求影响奉养老人、守业田契或留学约定。每份婚约会明列责任及其资助。

## 居所和费用

| 居所 | 人口与生计 | 孩子 |
|---|---|---|
| 迎入本家 | 配偶入户，计入收入、生活费与口粮 | 本家 |
| 入居亲家 | 本人迁出，夫妻留在家谱，生计归外家 | 亲家 |
| 两家往来 | 本人留家、配偶居外 | 成婚前约定 |

迁出前须交接族长和信物，暂停进行中的事务，并留至少一位在家成年人。外家成员继续长龄、经历生死，团聚后可恢复本家安排。

费用由媒礼、仪礼、聘资或妆资、安置费和路费组成。聘资结合亲家家境、对象能力与天资、本人的相应能力和职业经历、家族声望计算。匹配减免最多8两，留学守约减免最多4两；承担的责任会记录实际减免款。

| 礼仪 | 支出 | 本人首次成婚礼金 | 声望 |
|---|---|---|---|
| 家常小礼 | 4两、1石 | 0 | 0 |
| 乡里正礼 | 10两、3石 | 2两 | 2 |
| 广邀宾客 | 24两、6石 | 6两 | 5 |

每位迁入者安置费4两。同地路费0，乡村往来4两，其余异地8两。亲家一次相赠最多12两、6石，数额由扣除已承诺款后的家资确定。支出须足额支付，礼成后须留有银粮。确认页展示逐项费用、礼成余额、人口变化及当前安排下的次年预估。

## 亲家资助与身份

家庭资助在婚后6年内使用，可更换在家受惠人。粮助每年2石、共2年；银助每年4两、共3年；学识、手艺、医术、武艺援助每个符合安排的实际工作年加2点、共3年。银粮先从亲家家产留出，同一家只有一个基础资助名额。

| 长辈身份 | 办理条件、费用与收益 | 期限与名额 |
|---|---|---|
| 乡塾先生 | 付6两，实际读书额外学识1，共3年；完成1年后，应试成功率增加8个百分点，限1次 | 婚后6年 |
| 地方主簿 | 付4两，已有应试资格者实际任职，每年额外4两、声望1，共2年 | 婚后6年 |
| 商行东家 | 本金12两，实际行商1年后收回20两，净得8两 | 9年内最多3次，间隔3年，每单限2年 |
| 医馆师傅 | 付4两，指定人实际学医，每年额外医术3，共2年 | 婚后6年 |
| 营中校尉 | 付8两行装费，18岁、武艺35、体魄50，实际护卫1年得22两，净得14两 | 6年内最多2次，间隔3年，每单限2年 |
| 作坊匠师 | 婚约交付唯一图纸；已有作坊、手艺35者付20两，实际制器2年完工；此后作坊有人制器时年增4两 | 开工后4年，每年耗材10两，改坊成果随产业保留 |
| 宗族族老 | 付10两，实际读书1年，声望6、引见名额2 | 婚后6年，引见有效3年 |

长辈退任、离世后停止发起新事务，已经接下的事务按原期限继续。一次事务锁定办理人，共用信物及背景机会的一项额外事务额度。暂停释放额度，期限继续；商单未用本金与改坊未耗材料可退，服务费和行装费计为已花支出。

同人同属性的婚配成长加成按较高的一项结算，仅消耗实际生效来源的次数；银两加成同样取较高项。已经达到100的属性不消耗成长次数。项目完工所得单独记账。

## 婚后责任

| 约定 | 实际履行 | 结清规则 |
|---|---|---|
| 留学守约 | 指定人在原地4年内实际读书或学徒2年 | 主动迁出、逾期返还实际减免款，声望减2；指定人自然离世结束 |
| 接长辈同住 | 3年内由长辈之外的在家成年人实际持家；合格年付2两、2石 | 缺照料年声望减2、最多减4；长辈离世停止检查，未用照养款回亲家 |
| 守业耕田 | 赠1亩限售田；原地住满5年，并在7年内实际耕作5年 | 达成取得自由田契；主动结束或逾期归田、声望减4；夫妻自然离世后可选后人接手或归还，进度与期限保留 |

动荡年份被迫异地的约定，按实际受影响年延长期限，最多2年。责任收入、罚款和田地归属计入当年结算。

## 家法与物件

婚约最多授予一项家法或一件唯一物件。家法由配偶持有，在家配合实际安排时生效。其他族人通过实际传习获得，每人持有一项；师长需在世同住，传习占用师长的额外事务额度，可暂停、换同类师长并接续进度。

传承使用固定代际记录；新生、收养的孩子承接亲长的下一代，配偶沿用本人所属代际。补入亲家长辈或重新排辈时，同一代已用名额保持原记录。

| 家法 | 效果 | 受教条件 |
|---|---|---|
| 耕读相济 | 同年有人实际耕作，本代指定读书人实际读书时学识加1，共3年；同代共享名额 | 师长年长5岁，实际读书3年 |
| 药膳家法 | 持有人实际持家，花粮1石，最多2位休养者体魄加2 | 12岁、医术25，实际学医、行医或持家2年 |
| 持家有方 | 持有人实际持家，全年生活费减2，最低0；多位持有人共用此减免 | 18岁、经营25，实际持家或行商2年 |
| 重诺家训 | 持有人亲自完成不同类型亲家事务，声望加2，最多3项 | 18岁，受教期间在不同年份完成2类亲家事务 |

旧书实际读书时学识加2，共3次，剩余次数随保管人交接，可跨代使用。图纸消费后保留改坊成果，无法重复使用。在外族人保管的物件需团聚后交接。

## 年度往来与保存

亲家余粮、长辈遗书、夫妻团聚与铺面交接由真实家资、人物处境和固定年度随机结果触发。可接受或婉拒，同一段往来保留处理结果。领取时重新核对库存与条件。

婚约、资助、责任、事务、家法、传习、物件及往来全部进入存档；钱粮按生活费和口粮之前的实际结算处理，家史保留参与人及婚约编号，年度账本展示亲家来源。旧存档载入时补齐议亲世界，并保留原有夫妻关系。

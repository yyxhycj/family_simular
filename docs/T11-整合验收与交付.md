## 连续流程

`QA/T11.lua` 使用真实 `File`、`cjson`、`UI` 与生产模块，仅将 `jiaye_save.json`、备用保存和导出文件改到 `t11_qa_` 前缀。

1. 从生成器选取合法的完整家庭，创建运行家谱并保存；浏览家庭页。
2. 全部在世成年人安排务农，关闭生育计划，连续经营十年；每年清理待决家事，第一年执行一次家主交接。
3. 获得安稳终章资格时继续经营数据仍可读；确认终章后写入终章条件、档案和事实。
4. 终章后尝试推进年度被拒绝，运行家谱逐项保持不变。
5. 保存、导出、预演导入，重新创建 `App` 后浏览家庭和终章家史；终章、档案、账本、事实与保存修订号来自同一份内容。

实际运行记录为：家族“叶”，2 名成员，经营 10 年，17 条事实，10 本年度账，终章 `peaceful`，保存修订号 3。

## 失败路径

| 输入或状态 | 行为 |
| --- | --- |
| 生成器未产出合法整户 | 返回生成失败信息，当前草案保持不变 |
| 成长提醒引用的族人已不存在 | 事件标记为作废，旧对象写入 `cancelledMemberId`，运行期引用清空，后续保存继续执行严格引用校验 |
| 终章前未满足条件 | 终章请求拒绝，不写入终章、档案或条件快照 |
| 终章确认后继续推进年度 | 操作拒绝，运行家谱逐项保持不变 |
| 导出内容校验或预演导入失败 | 当前资料、草案、运行家谱和磁盘保存保持原样 |

# 成就系统

名称和条件以《成就命名修订 v1.1》为准，83 项原文保存在 `scripts/Jiaye/AchievementDefinitions.lua`。索引用于核对文稿，存档使用稳定的语义 ID。

当前开放 66 项。索引 33–35、65–78 共 17 项缺少完整剧情流程，`enabled = false`，不会判定、收录或出现在玩家界面。隐藏成就在启用后仍须真实达成才展示，未达成时不显示名称、条件或数量。

## 判定

`AchievementRules.lua` 从年度账本、人物成长起点、亲缘、族长任期、任务工作记录和已完成事实计算条件。`Achievements.lua` 负责一次性入册及跨局收藏。

- 完整年度以账本的实际经营年计算。安排岗位、点击结算之前、年后补粮均不能补出年度经历。
- 置产、住宅升等、新成员入户、族长交接和信物转交后，分别等待规定的实际生活或工作年度。
- 产业必须有合格成员经营；正常收入剔除信物和背景机会额外回款，培养费用同时记录应付与实付。
- 订单受理时保存原买家、地点、迁居次数和约定款项；交付时核对实际回款。暂停和换人保留原任务及费用。
- 背景旧识保留联系人身份及原址。借阅保留原物、约定接收人、有效借阅年度和押金结算。
- 引荐需实际增加收入或学识；数值达到上限时没有实际增加的部分不计帮助。
- 故事按固定故事 ID 去重，至少两个真实决策节点并完成有效收束。等待、暂停、换执行人及自动通知均不增加决策节点。
- 发展终章须由玩家正式确认。两户家族按不同 `runId` 识别，各自年数取最大值，导入和设备同步不累加同局年数。

家宅升等位于家业页，住宅依次为租下两间房、自家土屋、一方小院、旧宅深院，价值分别为 0、60、140、280 两，逐级支付差价；入住后完成年度才获得“新檐”。

## 存档及同步

存档版本为 3，兼容版本 1、2 及既有 V5 迁移入口。账户收藏保存 `achievements`、`achievementFamilies`、`achievementStories`；当前局保存人物成长起点。单项记录保留家族、世界、经营年、依据和达成时间。

所有游戏操作经 `App:Persist` 在候选副本中判定。人物、钱粮、成就共同写入交替存档并回读成功后，才替换页面中的收藏并提示入册。读取和浏览成就页不推进游戏或消耗本局随机数。

旧档仅根据已存在的可靠记录补记，并标注“旧档补记”。缺少成长起点或原物身份等历史依据时，从当前可核实状态开始积累后续经历。历史终章缺少家族身份时不猜测跨局关系。

正式账号同步沿用 `CloudSave.lua` 的 `clientCloud` 通道。选择云端或本机家谱时，均保留双方已获得的成就、故事和家族经历；当前局继续使用玩家选中的家谱。合并结果另存为待上传版本，上传后由原有流程重新读取核对。同一账号、同一项目之外的数据不能进入同步。

主页、游戏菜单和家史页均有入口。成就页提供分类、进行中、已达成、分页及达成依据。

## 验收

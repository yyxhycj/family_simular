# 字体与源文件

不附任何字体文件，不从设备提取或重新分发系统字体。继续系统回退：正文 -apple-system / BlinkMacSystemFont / PingFang SC / Microsoft YaHei / Noto Sans CJK SC / sans-serif；标题 Songti SC / STSong / SimSun / serif。出现于列表不代表要求安装或已获得再分发授权。

UrhoX并不自动支持CSS回退字符串，应接入项目实际平台字体接口；不支持时保留项目已合法使用字体。

源文件为独立分层SVG、UI组件总板、Python构建源码和JSON映射，没有PSD/原生Figma。PNG由矢量直接渲染，不是低分辨率画面放大。参考图中的字体名称和许可证不得当作授权文件。

# 接入（只改美术绑定）

1. 按原目录复制assets，读取data中的角色、事件、家宅、UI映射。PNG可先接现有引擎；SVG供编辑或支持矢量的运行端。
2. 人物创建或旧档显式迁移时分配artId并保存。渲染只读取，不消耗游戏随机数。已存在的artId不静默替换；4脸型可复用，不等于人物相同。
3. 同一artId用年龄阶段/病弱/已故资源；selected是正交叠层。已故固定死亡阶段。年龄分段只选择美术，不变更玩法。
4. 事件按类型和信物选择独立插画。来源、执行人、费用、结果仍为真实状态。未知类型不用无关图。
5. 家宅图只反映实际状态，不增加升级、破产或迁居规则。
6. 按钮使用源像素九宫格，字体/图标另渲染。PNG为straight RGBA；若引擎需要预乘，在资源管线只转换一次，避免黑边。
7. 不需要全量游戏测试。只做资源路径和四个关键页面查看；本包未修改代码、未执行UrhoX或手机真机验收。

# V7视觉规范 · 制作版1.0

运行资源是**原创可编辑矢量插画与PNG导出**，不是从V7旧截图放大小裁片。色彩、层级和组件沿用V7；人物与景物为矢量化表达，仍需美术精修笔触，不能宣称与手绘水墨概念稿完全一致。

| 用途 | 色值 |
|---|---|
| paper | `#f7f0df` |
| paperLight | `#fff9eb` |
| ink | `#293f37` |
| secondary | `#737466` |
| primary | `#355c49` |
| selected | `#e2e8d8` |
| gold | `#a48b58` |
| rule | `#d5c7a7` |
| danger | `#a2533b` |
| pressed | `#264738` |
| disabledSurface | `#dfddcf` |
| disabledInk | `#77796d` |

边线1逻辑尺寸，双框间距3；图标线宽1.65/24画布。主按钮圆角3、纸面面板10、底部面板上角12。阴影建议#142b21、0.055透明度、下移2、模糊6；PNG皮肤只含轻偏移影，真实柔影可由引擎实现。

纸纹：subtle本身色差很弱，可100%作底；透明纤维版建议整体0.35。不要两种叠满。medium/aged用于封面角落，不压在长正文下。朱印# a2533b（实际十六进制无空格），20–28逻辑尺寸，抽象家宅纹、非真实机构印章；动态家名/族长字独立渲染。

层级：纸面 → 弱山树影（约0.12–0.28）→ 图像/细框 → 状态 → 实时文字 → 焦点。装饰不拦截输入。

详情头像外部透明；头像是圆外透明；家宅/事件完整背景不透明。深背景用浅图标和不透明纸面内容，不抠白底。

源码SVG含头发、面部、五官、衣服、家宅、景物等命名层；不是PNG包SVG。没有PSD/原生Figma，没有字体文件。可导入矢量工具编辑，但不会自动成为完整Figma组件系统。

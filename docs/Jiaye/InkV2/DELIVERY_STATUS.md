## 版本与角色身份

- `artId` 仍使用 portrait_m01 / m02 / f01 / f02 这四个候选分组，但必须连同 `artVersion=ink_v2_review` 保存。
- 旧存档的 v1 图保持原样。只有明确选择新版美术配置的新局，或用户确认的迁移，才应用这些图；不静默换掉已认识的角色。
- 姓氏、职业、性格和角色身份不由美术图决定。不按列表位置或每次渲染抽脸。
- 四组图不是无限量原创角色；多个成员复用同一美术时，状态和关系仍完全独立。
- 已故头像使用死亡时年龄对应的底图；灰阶与角标仅表达状态，不抹去人物经历。

## 原尺寸与适配尺寸

全部原始图集保留在 `sources/`。`data/crop_map.json` 记录来源、原坐标和裁片像素。文件名 `_native.png` 是实际裁片；`_detail_768.png`、`_1200x560.png`、`_512.png` 都是明确标注的适配导出。

- 人物/信物保留RGBA透明；移除的只是在分格边缘出现的相邻碎片，未新增毛发或五官细节。
- 人物头像为256圆形，圈外透明，圈内浅纸底。病弱/已故是同底图色阶变化；选中为独立框。
- 家宅/事件为不透明场景。1200×560使用等比 contain 和浅纸留边，不拉伸、不声称高清重绘。
- 原图仍可能存在边缘杂点、手部/文字等生成细节偏差；适配稿适合接入核对，不标为精修终验。

## 不包括

没有字体文件、PSD或原生Figma，也不把扁平PNG伪称分层原画。继续系统字体回退。没有新增游戏规则、重新跑大规模测试或改动GitHub。

下一步真正缺的是以这些已固定分组和构图为依据逐张补成高清主稿，并核准身份与场景一致性，不需要重新写一套需求。

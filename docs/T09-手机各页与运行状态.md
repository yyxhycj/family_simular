## 页面与状态

家事页以待决事件为首项，随后显示按辈分分组的完整家谱。每个节点保留在世或已故状态、配偶、亲长、子女和查看入口；长家谱仍可进入“全体与筛选”。

族人页提供全体、在世、已故筛选和提交后生效的姓名检索。输入过程不重建页面；空结果提供清除筛选。人物页分为概况、安排、生活与经历，展示精确体魄、天资、性情、经历、五项能力和关系。岗位按 `Data.JobOrder` 排列，婚配、收养、应试、生育计划、族长交接和信物保管均先显示成本或结果，再确认写入。

家业页显示住宅、落脚处、公库、经营人、预计产业收益和最近一次实际产业收益。公市购粮和年度缺粮补购共同调用 `Economy.GrainPurchasePrice`；购粮、迁居、购田、作坊、商铺和接济均有确认页，事实记录、年鉴、资源和存档读取同一份运行数据。

藏阁分开显示本局物件、已解锁的下局资格和未解锁线索。未解锁线索只有来源与达成说明，不能提前带入本局。家史页用“任期／年鉴／终章”分栏呈现族长任期、账本、事实记录、参与人入口和十四条终章。

项目配置入口为 `main.lua`，屏幕方向为 `portrait`。`UI.SafeAreaView` 使用 `nativeMenuInset = true`，顶部和底部均保留安全区域；状态卡、底部导航、年度推进与关键操作触达高度为 44–48 逻辑像素。

## 正常路径

1. 进入默认随机摘要即可查看钱、粮、田、声望、人口、信物、首年净变化和总分，再从“就从这家开始”使用当前草案。
2. 家事页优先处理待决事件；确认页显示来源、参与人、成本、时间或结果，提交后同步更新事件、物件、事实、年鉴和存档。
3. 家业页按当前时期和地点报价购粮，资源变化与事实记录同步；置办家业后，预计收益与年度结算账本可分别查看。
4. 从任期、年鉴或终章进入人物，人物经历、关系和事实引用同一份运行状态。

## 失败路径

| 情况 | 页面和模型结果 |
| --- | --- |
| 购粮数量为零 | 拒绝操作，钱粮与事实记录保持原状 |
| 公库不足以购粮 | 显示所需银两，钱粮与事实记录保持原状 |
| 家业重复置办或公库不足 | 显示具体原因，资产和公库保持原状 |
| 事件已处理、执行人失效或本局落笔 | 显示对应原因，事件、物件和家史保持一致 |
| 人物已故 | 只显示概况、关系和生活经历；安排入口不写入状态 |
| 姓名筛选无匹配 | 显示空结果和清除筛选入口，家谱数据不改变 |

## 正常与失败路径

| 场景 | 实际输入与结果 |
|---|---|
| 同 seed | 1–128 的每个 seed 均两次生成并深比较一致；每户均通过正式 `ValidateDraft`，人口为 2–6 人、族长成年、信物均来自已解锁池。 |
| 不同 seed | 128 份样本得到 128 份不同成品、12 个姓氏、4 类人口数；样本覆盖 2–5 人，固定 seed 722 覆盖已锁定的 6 人夹具。 |
| 固定夹具 | seed 722 固定为顾氏、动荡、132 年、rngState `1416712955`、六人、族长 ID 1；夹具仍要通过正式草案校验。 |
| 换一家与恢复 | `ChangeHouse` 生成新候选且保存上一份；`UndoHouse` 恢复原草案，既有 Run 深比较不变。 |
| 无可用组合 | 注入生成器返回“无可用组合”后，原草案、Run 保持不变，反馈留在当前界面。 |
| 姓名骰子 | 仅推进 `nameSeed`，不变 `rngSeed`；本姓关联成员改姓，外姓成员保留原姓名。 |
| 本页随机 | 只返回该页候选，不直接写展示草案，不越界成为整户随机。 |
| 保存与重启 | seed 71 的 `NewRun` 写入草案随机源；保存后重建第二个 Lua VM，回读 `openingSnapshot`、`rngState`、家族、年份、人数一致。 |

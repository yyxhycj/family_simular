# T08｜十四条终章与只读

基线提交：`982abfc153612f68cd4a093684f7e0e25114bd2b`。

## 终章定义

`Data.Endings` 登记十二条发展终章与两条自动终章。自动终局记录同时保存 `automaticTrigger`：全员离世为 `living_members_exhausted`，钱粮破产为 `resources_exhausted`；当前 Run、`profile.endingRecords` 与终章事实使用同一触发来源。

| 类型 | 数量 | 写入时机 |
| --- | ---: | --- |
| 发展终章 | 12 | 条件具备后，由玩家在确认页落笔 |
| 自然终章“家谱落笔” | 1 | 年度结算后全体在世族人归零 |
| 家道终局“家道散尽” | 1 | 年度收支与自动兑换完成后，银两或存粮任一项≤0，或口粮仍未补足 |

每条条件行都保存条件名称、当前数值、目标数值、数值类型与事实来源。数值类型使用当前、累计、连续、代际累计、历史；事实来源指向年度账本、族长任期、家谱人物、迁居记录、援助记录、信物经历或公库。

## 正常路径

1. 发展终章达标后继续推进年度、安排人物或处理事件；资格本身不会结束本局。
2. 家主点击“以此落笔”后先查看条件快照，选择“继续经营”可返回游戏。
3. 确认落笔后，`Simulation.FinalizeEnding` 统一写入终章 ID、年份、族长、条件快照、已具备的发展终章、待决事件关闭清单和终章事实。
4. 当前局与 `profile.endingRecords` 保存同一份快照；家史、首页与存档读取同一份终章记录。
5. 两条自动终局复用同一提交入口，自动关闭尚未处理的事件；“家谱落笔”由在世族人归零触发，“家道散尽”由年末银两≤0、存粮≤0、口粮未补足三项条件中的任一项触发。
6. 年度账本保留 `resourcesExhausted`，家史展示破产年度的实际钱粮余额；终章保留银两、存粮与口粮状态三项条件快照，以及参与人的既有经历。负数余额按实际数值保存。

## 边界与失败路径

| 情况 | 结果 |
| --- | --- |
| 未达成发展终章 | 拒绝写入，当前局和档案保持原状 |
| 试图确认自动终章 | 提示对应自动条件，当前局和档案保持原状 |
| 年末银两或存粮任一项≤0 | 自动写入“家道散尽”，关闭待决事件，人物生平与家史继续可读 |
| 银两不足补购缺少的口粮，或卖尽余粮仍无法填平开支 | 自动写入“家道散尽”，保留实际兑换与钱粮余额 |
| 自动兑换后银两、存粮均大于0且口粮已补足 | 可继续安排并推进 |
| 同年更换族长 | 任期未满一年，不计入真实交接 |
| 婚入同代成员 | 继承配偶代际，不增加传承代数 |
| 选择不同合法开局年份 | 实际经营年数从 `yearIndex` 计数，开局年份不计入 |
| 终局后安排人物、家业、事件或信物 | 领域入口拒绝，页面只展示记录 |

## 页面状态

终局后家族页显示准确的自动条件与三项快照。族人页改为查看生平；家业页展示封存的公库和迁居记录；信物页展示封存的物件状态、保管人和调查记录。家史页同时显示本局终章快照与全部终章现况，年度账本标出破产年度的实际银两、存粮和口粮状态。
